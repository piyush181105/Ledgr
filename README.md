Ledgr: Personal Expense Tracker
Ledgr is a full-stack personal finance application designed to help users track their income and expenses efficiently. This project was developed as a major graduation project for my Bachelor of Computer Applications (BCA) degree.

Backend: Node.js, Express.js

🛠️ How to Run Locally
Prerequisites
Node.js installed on your machine.

Git installed.

Setup Instructions
Clone the repository:

Bash
git clone https://github.com/piyush181105/Ledgr.git
cd Ledgr
Install dependencies:

For the backend:

Bash
cd backend
npm install
For the frontend:

Bash
cd ../frontend
npm install
Configure Environment Variables:

Create a .env file inside the backend/ folder.

Add your necessary keys (e.g., PORT, MONGO_URI, JWT_SECRET).

Start the application:

Start the server (inside backend/): npm start

Start the frontend (inside frontend/): npm run dev
